## Étape 4 : volume nommé (persistant)

$ docker volume inspect mon_volume_persistant --format '{{.Mountpoint}}'

$ docker exec B3_soir cat /mnt/fichier.txt

$ docker run --rm -v mon_volume_persistant:/mnt alpine:3.20 cat /mnt/fichier.txt

## Étape 5 : base PostgreSQL qui survit à sa suppression

3c226d7140aecf14587814ad8d7cee5f571df7c29cd9842081bdbb4185aa78c2

$ until docker exec pg pg_isready -h 127.0.0.1 -U postgres -q; do sleep 1; done; echo base prête
